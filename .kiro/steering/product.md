# MoneyMind — Product Overview

MoneyMind is a personal finance management web app that helps users track spending, manage budgets, set financial goals, and connect bank accounts via Plaid.

## Core Features

- **Transaction management** — manual entry and automatic sync from connected bank accounts (Plaid)
- **Budget tracking** — recurring category-based budgets with real-time progress vs. actual spending
- **Financial goals** — create savings targets, track progress, and log contributions
- **Analytics dashboard** — spending by category, monthly trends, and spending summaries
- **AI chat advisor** — conversational financial assistant powered by OpenAI, scoped to the user's own financial data
- **Bank connectivity** — Plaid Link integration for read-only access to bank transactions

## Target Users

Individual consumers who want a unified view of their finances without switching between bank apps.

## Deployment

- Frontend: `https://moneymind.us` (Render)
- Backend API: `https://moneymindus.onrender.com`
- Local dev: frontend on `localhost:4200`, backend on `localhost:5000`
